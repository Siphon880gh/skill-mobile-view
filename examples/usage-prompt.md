# Example Prompts for Using the Mobile View Skill

When you have the `mobile-view` skill installed, you can use the following prompts to guide your AI agent:

## Basic Request
"Check the mobile view of the homepage to see if the hamburger menu is working."

## Specific Device Request
"Inspect the site using the Pixel 7 preset. I want to see how the hero image crops on Android devices."

## Debugging Request
"The mobile site is showing the desktop header. Use the `mobile-view` skill to verify the User Agent and reload the page to force a mobile response."

## Verification Request
"Verify that `wp_is_mobile()` is returning true by checking the rendered HTML for the \'.mobile-only-banner\' class."
